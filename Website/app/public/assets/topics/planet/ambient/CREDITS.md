# Planet — ambient imagery credits

Sourced from Wikimedia Commons; licences verified on each file page at download time.
Each file was resized to 1800px wide and centre-cropped to a ~21:9 hero band, then
JPEG-encoded under 400 KB. No colour grading is baked in — the Level-1 hero applies its
dark scrim and accent tint in CSS, so these remain unretouched apart from resize/crop.

Attribution is required for the CC BY / CC BY-SA files below; keep this file with the
images, and surface the credit in the page footer or an image-credits page before
publishing.
